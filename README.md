# claude-antiban

> [!CAUTION]
> ## 一定一定要看完这份 README；实在没时间，至少要看 [第 12 步：再跑一遍检测](#12-再跑一遍检测)，并用里面的两个网站查一遍。

这个 skill 用来把电脑的上网环境配置好，让浏览器、Claude 桌面端和 Claude Code 都从同一个固定的海外 IP 出去，同时让系统时区、浏览器语言这些和 IP 的所在地对得上。

skill 是给 AI agent 用的。agent 读 [SKILL.md](SKILL.md)，和你分工把电脑配好，或者给已经配好的环境做体检。这份 README 说明整体要做哪些事，以及每一步为什么要做。

它能做的，是把环境里互相矛盾的信号消掉，保证不了账号一定安全。使用 Claude 请遵守 Anthropic 的服务条款和当地法律。

## 你和 AI 怎么分工

| AI 来做 | 你来做 |
|---|---|
| 先跑一遍检测，看清起点（第 6 步） | 买 IP、Claude 账号和会员（第 1 步） |
| 写好 Clash 的国内直连规则和 DNS 覆写（第 7 步） | 装好 Clash、导入订阅、拨好开关、设代理变量，让代理先跑起来（第 2–5 步） |
| 关系统 IPv6、固定网卡 DNS（第 8 步），对时区（第 9 步） | 决定要不要删厂商字体（第 10 步） |
| 清理国产厂商字体（第 10 步，你同意了才删） | 浏览器设置（第 11 步） |
| 最后再测一遍，和起点对比（第 12 步） | 检测通过后登录 Claude（第 13 步） |

下面「步骤和原因」的每一步开头，都标了由谁来做。让代理先跑起来这一步必须你先做，因为 AI 自己也要靠代理联网。你要做的事都写在 [SETUP.md](SETUP.md) 里，配了截图。AI 到了该你做的地方会停下来，告诉你看哪一节、做完回它什么。

> [!TIP]
> **不用等 IP 到手再开工。** 买 IP 往往要等卖家开通。手头有临时能用的代理（比如原来的机场）的话，先导入 Clash 用着，就可以让 AI 开工：检测、改 DNS、关 IPv6、清理字体，这些都不依赖你买的 IP。做到要检查 IP 的那一步，它会停下等你。
>
> 这期间不要打开或登录 Claude，也不要用 Claude 来带你做：临时代理的 IP 多半是很多人共用的，被 Claude 看到，前面就白配了。具体做法见 [SETUP.md](SETUP.md) 开头的「IP 还没买到？」。

## 需要你配合的地方

AI 干活时，有几处需要你动一下手。每一处它都会先说清楚要做什么、为什么，你照着做就行：

- **检测页别关。** 检测是在你自己的浏览器里跑的，因为要测的就是你登录 Claude 的那个浏览器。检测页弹出来以后大约 15 秒，等它显示"完成"再关。
- **弹出管理员确认时点「是」。** 关系统 IPv6、固定网卡 DNS、改时区、删装给所有用户的字体，都是改系统设置，Windows 要求管理员权限。AI 会提前告诉你马上要弹窗、为的是哪一步；它没提前说过的弹窗，不要点。
- **同意删哪些字体。** AI 会先列出你电脑上装了哪几款厂商字体，讲清楚删掉有什么影响、备份在哪、怎么装回去。你说同意，它才删。不想删也可以，代价是指纹评分会高 10 分。
- **在 Clash 里把「DNS 覆写」关掉再打开。** AI 改好 Clash 的配置后，Clash 要重新读一遍才会生效。不要用退出 Clash 再打开的办法，退出时 Clash 会关掉系统代理。
- **IP 到了换订阅。** 先用临时代理开工的，IP 到了以后在 Clash 里换上新订阅，再告诉 AI。
- **IP 不合格时找卖家。** 检测发现出口国家不对，或者 IP 有滥用记录，AI 会停下来，请你找卖家换。

## 思路

Claude 能用来判断你的，主要有两样东西：

- 连到它服务器的 IP：在哪个国家，是住宅还是机房，会不会变来变去；
- 浏览器和系统透露出来的环境：时区、语言、字体，WebRTC 有没有漏出真实 IP。

据公开的逆向分析，Claude Code 还会读取系统时区。

所以目标很明确：所有 Claude 入口都走同一个固定出口，电脑环境和这个出口保持一致。微信、迅雷这些软件怎么上网无所谓，Claude 看不到。

需要注意的是，"走代理"这件事由程序自己决定。系统代理和 `HTTPS_PROXY` 环境变量都只是给程序的建议，有些程序会听，有些不听。实测开着系统代理时，PowerShell 走的是海外节点，curl 和 Node.js 用的却是本地运营商的真实 IP。下面的步骤因此会对每个 Claude 入口单独处理，最后用实测出口来验收，而不是看开关有没有打开。

## 要买的东西

开始配置之前，先买好两样东西：

1. **一个独享的静态 IP。** 怎么挑，见下面第 1 步。
2. **Claude 账号和会员。** 一般是买一个普号，再买 iOS 礼品卡充值的会员。推荐到 [PriceAI](https://priceai.cc/channels?platform=Claude) 上买，里面汇集了很多家卡网商家，各种需求基本都能找到，比好价直接点进对应的店铺下单。

账号可以先买好，但要等第 12 步检测通过后再登录，原因见第 13 步。IP 要等卖家开通的话，不用干等，见上面「你和 AI 怎么分工」下面的提示。

## 步骤和原因

### 1. 买一个独享的静态 IP

**谁来做**：你。IP 还没到手时，AI 可以先开工，见上面的提示。

出口 IP 本身就是最直接的信号。

- 共享 IP 会被同一节点上的其他人连累；
- 频繁换 IP、换国家本身就可疑；
- 机房 IP 比住宅或 ISP 类型的 IP 更容易被各家数据库标成代理。

所以要选：独享、固定不变、在 Anthropic 支持的地区，最好是住宅或 ISP 类型。

### 2. 用 Clash Verge 导入订阅，选定节点，选对模式

**谁来做**：你。

节点选好以后就不要再换，Claude 看到的出口才会一直是同一个。

模式按订阅里的节点数量来选：

- 只有一个节点，用规则模式。海外网站走节点，国内网站直连，出口也不会变。
- 有多个节点，用全局模式。规则模式下，订阅往往会把 Claude 分进"自动选择"组，出口就会随测速结果跳来跳去。

### 3. 打开系统代理，不开虚拟网卡（TUN）

**谁来做**：你，在 Clash 设置页拨开关。

浏览器和 Claude 桌面端都按 Windows 系统代理上网，打开系统代理，这两个入口就走节点了。

很多教程让开 TUN。TUN 会接管所有程序的流量，但代价不小：

- 微信、QQ 也被迫走海外节点，登录容易出问题；
- 连国内服务器的 SSH、远程桌面会绕到海外再回来；
- 和电脑热点、虚拟机网卡容易冲突；
- 更要紧的是，Clash 一旦退出，所有流量立刻回到真实 IP。

Claude 只需要它自己的三个入口走代理，用不着 TUN。

### 4. Clash 的其余开关：开机自启、关 IPv6

**谁来做**：你，在 Clash 设置页拨开关。

**开机自启。** 不管用的是 Clash 还是 v2rayN，都要设成开机自启。开机后代理软件没起来，浏览器就会用真实 IP 上网。另外还有一个容易忽略的地方：Clash Verge 正常退出时，会顺手把系统代理关掉，浏览器随即改用真实 IP。所以平时不要手动退出代理软件；真要退出，先关掉 Claude。

**关掉 Clash 的 IPv6。** 代理只接管 IPv4 流量。IPv6 开着，就有流量会绕开代理出去。

### 5. 设置持久的 `HTTPS_PROXY` 环境变量

**谁来做**：你，在 AI 开工前粘贴一行命令。AI 自己也要靠它走代理，所以得你先设；之后 AI 会核对端口对不对。

Claude Code 不看系统代理，只认 `HTTPS_PROXY` 这个环境变量。把它存成永久的用户变量，Claude Code 才会走代理。

这样还有一个好处：Clash 没开的时候，Claude Code 会直接报错，不会悄悄用真实 IP 连接。代价是 pip、npm、git 这类工具也会跟着走代理，Clash 关掉时它们会连不上。

### 6. 先跑一遍检测，看清起点

**谁来做**：AI 跑；检测页弹出来以后，你别关它，大约 15 秒。

改任何东西之前，先把现在的样子测一遍。一台没处理过的中文电脑，fuck-claude 的"中国用户"评分很容易到 50 分以上，主要来自这几项（括号里是这一项最多加多少分）：

- 系统时区是北京时间（24）；
- 浏览器语言中文排第一（18）；
- 装了中文字体（14）；
- 装了 WPS、小米、阿里这些厂商的字体（10）；
- WebRTC 漏出真实 IP（10）；
- 用国产浏览器（8）。

测完以后，AI 会告诉你命中了哪几项、每一项在后面哪一步由谁来改。第 12 步再测一遍，两次一对比，就知道改到位没有。

### 7. 国内网站直连、DNS 覆写

**谁来做**：AI 写好；你在 Clash 里把「DNS 覆写」开关关掉再打开，让它生效。

**国内网站直连。** 用规则模式时，加两条规则让国内网站直连（`GEOSITE,cn` 和 `GEOIP,CN`）。国内网站本来就不需要绕到海外，直连更快，银行、12306 这类网站也不会因为海外 IP 拒绝访问。

**DNS 覆写。** 把海外域名的解析交给加密 DNS，并经代理发出；国内域名交给阿里、腾讯的加密 DNS。这样做的效果是：

- "你在访问 claude.ai"这件事，不会被国内的 DNS 看到；
- 国内域名照常解析，代理断了也不受影响。

**网卡 DNS 不要改成 `127.0.0.1`。** 改了以后，所有程序都会向 Clash 查地址，而 Clash 回给它们的是只有它自己认得的临时地址。迅雷、网易云这类不走代理的软件拿着这种地址自己去连，就会断网。

### 8. 在系统里也关掉 IPv6、固定网卡 DNS，并让它每次联网都自动再做一遍

**谁来做**：AI。它会弹出管理员确认窗口，你点「是」。

光在 Clash 里关 IPv6 不够，网卡上的 IPv6 也要关。

网卡 DNS 固定成 `1.1.1.1` / `8.8.8.8`。这样不走代理的软件就不会再用运营商的 DNS，运营商也就不能顺手记下你查过哪些域名，DNS 检测里系统这条路也不会出现国内运营商。代价是：酒店、机场这类需要网页登录的 Wi-Fi，登录页可能弹不出来，这时临时把 DNS 改回自动就行。

换 Wi-Fi、插新网卡、开手机热点时，新出现的网卡默认会打开 IPv6，DNS 也会变回自动。所以要装一个计划任务，每次开机、每次联网都自动再设一遍。

### 9. 系统时区对齐节点所在地

**谁来做**：AI，和第 8 步一起做，你同样只要点「是」。IP 还没到手时，这一步要等 IP 到了再做。

系统时区是唯一一个能直接对上 Claude 实际判定方式的信号：Claude Code 会读它，网页也读得到。

- **先确定节点在哪个时区。** 各家 IP 数据库给出的位置经常不一致，有的说美东、有的说美西，所以按几家数据库的多数结果来定，不要只看一家。
- **改好后关掉"自动设置时区"。** 不关的话，系统会按定位把时区改回北京时间。
- **换节点后重新对齐。** 以后节点所在地变了，时区要跟着改。

### 10. 清理国产厂商字体

**谁来做**：AI 先列出来、讲清楚，你同意了它才删；删的时候你点「是」，删完重启电脑。第 6 步没测出这一项，就跳过。

WPS、小米、华为、阿里这些厂商的软件，会顺手往电脑里装自己的字体，比如 WPS 带的方正书宋、方正楷体，还有 MiSans、鸿蒙黑体、阿里巴巴普惠体。网页能测出这些字体在不在，fuck-claude 把它记作 10 分。

删掉的影响：用到这些字体的文档，多半是 WPS 里的，会改用别的字体显示，排版可能变样。AI 删之前会把字体备份到一个文件夹，想要回来随时能装回去。删完要重启电脑才生效；以后重装或更新 WPS，可能又会装回来，再测一遍就知道。

系统自带的中文字体（微软雅黑、宋体这些）删不掉，也不用删，那 14 分只能留着。它只影响网页指纹，Claude Code 不读。

### 11. 设置浏览器

**谁来做**：你。这些设置都在浏览器里，AI 点不了。

**装 WebRTC Network Limiter，选 "Use my proxy server"。** WebRTC 是浏览器做音视频通话用的，它会绕开代理去探测本机的真实 IP。这个扩展让 WebRTC 也只能走代理。

**关掉"安全 DNS"。** 开着的话，浏览器会绕过系统和 Clash，自己去做 DNS 查询，走向不受控制。

**把首选语言和界面语言都换成节点所在国的语言。** 网页能读到这两项，中文排在第一位，就是很明显的中文环境信号。

**启动时不要恢复上次的标签页；用 Edge 的话，还要关掉"启动增强"。** 开机时浏览器可能比 Clash 先启动，这时恢复出来的 claude.ai 标签页走的是真实 IP。

**用干净的环境登录 Claude。** 接入新 IP 之前清掉 Cookie，或者新建一个浏览器用户专门用来登录 Claude。另外，不要用国产浏览器或微信内置浏览器登录。

### 12. 再跑一遍检测

**谁来做**：AI 跑；检测页同样别关。下面两个网站可以自己打开看看。

前面每一步都只是设置，最后要用实测结果确认，并和第 6 步的起点对比。

自检脚本会在你平时用的浏览器里打开一个本地检测页，同时在后台测各个入口的出口。主要确认这几件事：

- 三个 Claude 入口是不是同一个海外出口；
- DNS、WebRTC、IPv6 有没有泄漏；
- 时区和语言是否与 IP 对得上；
- fuck-claude 网站的"中国用户"指纹评分是多少。

结果里每个问题都会注明，该回到哪一步去改。AI 会把两次的分数和各项变化列给你看。

想用网页快速看一眼的话，用平时登 Claude 的浏览器打开下面两个网站：

- [ip.net.coffee/claude](https://ip.net.coffee/claude/)：一站式检测页，能一次看清 Claude 看到的 IP、这个 IP 的风险评分、DNS 有没有泄漏、WebRTC 有没有泄漏。
- [fuck-claude.vercel.app](https://fuck-claude.vercel.app/zh/)：点「开始检测」，看浏览器环境的"中国用户"指纹评分，越低越好。自检里的指纹评分用的就是它的规则。

用规则模式时，ip.net.coffee 上的「中国出口 IPv4」和「网站分流测试」会显示你的国内 IP，这是正常的。第 7 步让国内网站直连了，这两项测的正是你打开国内网站时从哪出去。要看的是「Claude AI 出口 IP」和「Cloudflare 出口 IP」这两格，它们应该是你的节点 IP。

### 13. 检测通过后，再登录 Claude、开会员

**谁来做**：你。

登录时用的是哪个 IP、什么样的环境，Claude 那边都看得到。环境没配好就登录，账号见到的第一个 IP 就是你的真实 IP。

不要在手机上下载 Claude App。

### 14. 日常使用

**谁来做**：你。

- 开机后等 Clash 连上，再打开 Claude；
- 不要在 Claude 开着的时候退出 Clash；
- 一个 IP 只登录一个账号；
- 换了网络、更新了订阅或者换了节点之后，再跑一遍检测。

前面那些设置，都可能被这几件事悄悄改掉。
