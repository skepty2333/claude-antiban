# 出口 IP：买什么样的，怎么判断好坏

## 选购标准（按重要性）

1. **独享**：只有你一个人用。共享节点的其他人一旦被封，可能连累你。
2. **静态**：IP 长期不变。频繁换 IP、换国家本身就是风控信号。
3. **地区**：在 Anthropic 支持的国家或地区（美国、日本、新加坡、台湾等），不能是中国大陆、香港、澳门。
4. **类型**：住宅或 ISP（家宽）IP 优于机房 IP。机房 IP 能用，但更容易被各家数据库标成代理/VPN。
5. 节点有设备数和流量限制的，不要外传、不要共享。

## 用自检判断

自检的"出口 IP 质量"一项汇总了两个公开数据源：

| 标记 | 含义 | 怎么办 |
|---|---|---|
| 有滥用记录（`is_abuser`） | 这个 IP 被记录做过坏事 | 找卖家换 IP |
| 机房 IP（`is_datacenter` / ip-api `hosting`） | 来自数据中心或托管商 | 能用；预算允许就换住宅/ISP IP |
| 被标记为代理/VPN（ip-api `proxy`） | 公开库已知它是代理出口 | 同上 |
| 住宅 IP（`isResidential`） | 理想情况 | 保持 |
| 信任分（net.coffee `trust_score`） | 0–100，越高越好 | 作为对比参考，不单独定论 |

IP 库之间常常不一致，同一个 IP 可能一家判住宅、另一家判机房。看多数结论，不要被单一来源吓到。

## 用法上的一致性

- 客户端里只用这一个节点，用 `select` 组固定，不要放进自动测速组。详见 `routing.md`。
- 系统时区、浏览器语言和这个 IP 的所在地保持一致。时区以自检给出的多数库结果为准，详见 `browser-and-device.md`。
- 一个 IP 只登一个 Claude 账号，不要几个账号轮流登。
